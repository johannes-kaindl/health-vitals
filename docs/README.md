# Health Vitals — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first dashboard.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Export your data from the Health app, import it and read the dashboard. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Export.xml not found in the zip", "Import failed", an empty dashboard, an outdated cache. |

The [README](https://github.com/johannes-kaindl/health-vitals/blob/main/README.md) covers what the plugin does, how metrics and sleep are aggregated, the privacy model and the few things it remembers.

`SMOKE.md` and `superpowers/` hold maintainer material (the GUI smoke checklist and early design notes) and are not user documentation.
