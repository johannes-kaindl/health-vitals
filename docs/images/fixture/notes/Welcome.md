# Recording vault

This vault exists only to produce the screenshots in the README. Its contents come from
`docs/images/fixture/` and are rebuilt by `npm run shots -- --setup`.

The health data behind the dashboard is **synthetic** — generated by
`make-health-cache.mjs` with a fixed seed, so two runs produce the same pictures. No real
health data ever leaves a machine through this repository.

Open the dashboard with the ribbon icon (♥) or the command palette:
**Health Vitals: Open dashboard**.
